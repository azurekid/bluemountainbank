Usage Notes & Guidelines

  • All tools work seamlessly from the /admin directory when deployed
  • JavaScript files are automatically referenced from ../js/ directory
  • Tools automatically detect Azure vs Local data sources with visual indicators
  • Use Debug User Data tool first to verify system connectivity
  • Upload tools require valid Azure SAS tokens with proper permissions
  • All diagnostic tools provide real-time status and error reporting
  • Session data and user preferences are preserved across tool navigation
